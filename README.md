# CyberSentinel

CyberSentinel is a Python-based security log analysis tool
designed to detect suspicious activities and generate alerts.

## Objectives

- Read and analyze security logs.
- Detect repeated failed login attempts.
- Generate alerts with severity levels.
- Export alerts to JSON and CSV.
- Display results through a Streamlit dashboard.

## Technologies

- Python
- Git and GitHub
- Pandas
- Streamlit
- Pytest
